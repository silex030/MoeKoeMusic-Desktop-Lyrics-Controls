# 桌面歌词悬浮控制

MoeKoe Music 插件。鼠标移到内置桌面歌词上时，显示 **上一曲、播放/暂停、下一曲、红心** 四个按钮；移开后随歌词原有控制栏一起隐藏。

- 红心将当前歌曲加入「我喜欢」，复用播放器原有收藏按钮。
- 播放/暂停图标跟随实际播放状态，不在点击后假设播放已成功。
- 歌词锁定后仍可悬浮操作；保留原有解锁、颜色、字号和关闭控件。
- 不影响拖动、窗口缩放和歌词锁定的鼠标穿透机制。
- 不需要启用播放器 WebSocket API，不启动后台服务或本地程序。

## 安装

需要 **MoeKoe Music 1.7.0 或更高版本**。支持内置桌面歌词窗口，不适用于第三方原生桌面歌词插件。

1. 下载本仓库 ZIP，或下载发布的 `desktop-lyrics-hover-controls-v1.0.0.zip`。
2. 在 MoeKoe Music **设置 → 插件 → 本地安装** 中选择 ZIP。
3. 重启播放器，并在播放器设置中打开桌面歌词。
4. 鼠标移到歌词文字上，即可使用控制栏。锁定状态下，将鼠标移到按钮上再点击。

卸载后请重启播放器，以清除已加载到现有窗口的内容脚本。

## 收藏说明

请先登录酷狗账号，并打开一次音乐库以加载「我喜欢」歌单。暂无歌曲、本地音乐和云盘音乐时，红心不可用。

红心是**加入收藏**按钮，不执行取消收藏。实际收藏结果以播放器提示和歌单内容为准；「已发送收藏请求」仅表示已触发播放器操作，网络失败时不会声称收藏成功。

## 隐私与兼容性

插件仅在 MoeKoe Music 页面运行。播放控制使用现有桌面歌词 IPC；收藏通过同源窗口间的 `BroadcastChannel` 通知主播放器调用原有按钮。插件不发送额外网络请求、不读取本地文件，也不收集或传递登录令牌。只读取页面已有的当前歌曲、账号是否登录、我喜欢歌单是否已加载这些状态。

已验证开发页面与打包后的 `file://` 页面可加载内容脚本并通信。Windows/macOS 的真实桌面鼠标穿透仍遵循播放器实现，需要在相应系统上进一步验证；Linux 的 Electron 集成测试使用虚拟显示器。

## 开发与测试

无需编译或安装依赖即可作为插件使用。可选打包：

```sh
python3 scripts/package.py
```

集成测试使用 Node.js 22+ 自带的 WebSocket，连接运行中的 MoeKoe Music Electron 调试端口 9222。应在测试专用的播放器资料目录中执行：测试会临时设置测试歌曲和账号状态，随后恢复页面存储，并拦截收藏接口以避免写入真实歌单。

目前测试针对 Linux 的 Xvfb 环境，需要 Python 3、libX11 和 libXtst。启动播放器的 `xvfb-run` 进程 PID 应记录在服务状态 JSON 的 `electron.pid` 中，通过 `MOEKOE_SERVICE_STATE` 指定该文件；默认读取云环境的 `/workspace/.moekoe-environment/runtime/services.json`。测试只控制这个进程启动的 Xvfb，找不到时会停止。开发页面应使用 `http://localhost:8080`，API 使用 `http://127.0.0.1:6521`；可通过 `MOEKOE_DEBUG_PORT` 指定调试端口。

```sh
python3 scripts/package.py
npm test
```

测试覆盖安装 ZIP、歌词悬浮/移开、锁定及解锁、按钮 IPC、播放状态同步、重复注入、主窗口路由切换和实际收藏请求的目标歌单及歌曲参数。测试不把模拟 API 响应当作真实酷狗服务验证。

## 插件市场

官方市场通过 [上架申请](https://github.com/MoeKoeMusic/MoeKoeMusic-Plugins/issues/new?template=plugin_publish.yml) 收录插件，需要维护者审核。仓库中存在 `manifest.json`，可直接下载整个仓库 ZIP 安装，无需编译。
